# DagaDyn

[English](README.md) · [Italiano](README.it.md) · [Español](README.es.md) · [Français](README.fr.md) · [Deutsch](README.de.md) · [Português](README.pt.md) · [Nederlands](README.nl.md) · [Svenska](README.sv.md) · [Polski](README.pl.md) · [Čeština](README.cs.md) · **Русский** · [日本語](README.ja.md) · [한국어](README.ko.md) · [中文](README.zh.md)

Расширение для SketchUp, которое делает объекты динамичными. Каждое свойство
группы, компонента или секущей плоскости переходит из одного состояния в
другое за выбранное вами время, по кривой, которую вы рисуете сами, и вы
видите это прямо в сцене. Двери, которые открываются, лифты, которые
поднимаются, лампы, которые зажигаются, сечения, которые проходят сквозь
здание.

⬇ **Скачать**: [последняя версия](https://github.com/Dagadam/dagadyn/releases/latest) (все версии: [Releases](https://github.com/Dagadam/dagadyn/releases))

## Что умеет

- **Свойства**: сдвиг (от того места, где стоит объект), положение, поворот,
  размеры (ширина, глубина, высота), масштаб, цвет, непрозрачность,
  видимость и тег. Секущие плоскости сдвигаются, включаются и выключаются.
- **Состояния и кривые**: у каждого свойства есть начальное состояние,
  конечное и длительность; дополнительные состояния образуют
  последовательность. Каждый переход идёт по кривой: линейная, разгон,
  торможение, с перелётом, отскок, упругая, ступени — или ваша собственная,
  нарисованная в редакторе кривых перетаскиванием точек.
- **Шкала времени**: Пуск, Пауза, Стоп и полоса, чтобы увидеть любой
  момент. Один раз, по кругу или туда-обратно, с нужной скоростью.
- **Запуск**: объект начинает со шкалой времени, после того как закончит
  другой (плюс ожидание), или **по действию**: щелчок инструментом
  *Действие*. Он может каждый раз начинать сначала или идти вперёд, а в
  следующий раз назад (двери, ящики).
- **Цепочки, которые следуют**: объекты в цепочке за объектом, который идёт
  вперёд и назад, повторяют его направление, туда и обратно, каждый — когда
  закончит предыдущий (рычаг, затем подъёмный мост).
- **Проект не меняется**: анимации двигают объекты, не трогая модель.
  *Стоп* всё возвращает, и файл всегда сохраняет состояние покоя;
  *Оставить* оставляет объекты такими, как сейчас (Ctrl+Z отменяет).
- **Внутри объектов**: анимации сохраняются в файле `.skp` и копируются
  вместе с объектом. Если выделено несколько объектов, изменение применяется
  ко всем, с учётом положения и размеров каждого.
- **Траектории в виде**: путь движущихся объектов с точкой для каждого
  состояния (SketchUp 2023 и новее).
- **Предпросмотр при правке**: при изменении значения состояния объект
  показывается в этом состоянии.
- **Отдельно или с [DagaWASD](https://github.com/Dagadam/dagawasd)**: DagaDyn больше
  ничего не нужно. Если установлен и DagaWASD 1.3.0 или новее, объекты
  двигаются и когда вы ходите, осматриваете модель, проигрываете маршруты и
  экспортируете видео (кадр за кадром, во времени видео). Движущиеся
  платформы везут вас с собой, а клавиша «Действие» запускает объекты,
  которые начинаются по действию.
- Панель на 36 языках. Если установлен DagaWASD, она берёт его язык и
  внешний вид.
- **Доступность**: см. [ACCESSIBILITY.md](.github/ACCESSIBILITY.md).

Требования: SketchUp 2023 или новее. Разработано и проверено в Windows; на
Mac пока не проверялось.

## Как пользоваться

1. *Расширения › DagaDyn › Панель анимаций…* (или панель инструментов).
2. Выделите группу, компонент или секущую плоскость. В *Анимация › Объект*
   выберите свойство для анимации и нажмите *Добавить*.
3. Введите начальное и конечное состояния (*⌖ текущее* берёт значение,
   которое у объекта сейчас), длительность и выберите кривую. Щёлкните по
   маленькой кривой, чтобы нарисовать свою.
4. Нажмите **▶** (или пробел в панели). **⏹** всё возвращает на место.

Для объектов, которые начинаются «по действию», возьмите инструмент
*Действие* (панель инструментов или меню) и щёлкните по объекту в модели;
Esc выходит из инструмента.
Под указателем объект, который запустится, обводится рамкой и показывает
своё имя. Если ни один объект не начинается со шкалой времени, кнопка **▶**
становится **☝** — инструментом *Действие*.

## Установка

Скачайте **`dagadyn-<версия>.rbz`** из [последней
версии](https://github.com/Dagadam/dagadyn/releases/latest) (в разделе
*Assets*) и установите через *Расширения › Extension Manager › Установить
расширение*.

Настройки хранятся в `%APPDATA%\DagaDyn\settings.json`: обновление их не
стирает. Анимации хранятся в моделях, а не в расширении.

## Разработка

Код, комментарии и список изменений — на итальянском; как расширение
устроено внутри, описано в [SVILUPPO.md](SVILUPPO.md).

- `installa.bat` копирует исходники в папку Plugins каждого найденного
  SketchUp.
- `tools\run_tests.bat` запускает тесты (Ruby с имитацией SketchUp; тесту
  кривых нужен ещё Node.js).
- `ruby tools\test_live.rb` проверяет в настоящем SketchUp через мост
  DagaWASD (нужна открытая новая модель, *Файл › Создать*; оставляет новую).
- `ruby tools\crea_rbz.rb` собирает пакет в `dist\`.
- Номер версии есть только в `dagadyn.rb` (`VERSION`); у каждой версии свой
  раздел в `CHANGELOG.md`.
- Этот README есть на нескольких языках (`README.md` на английском,
  `README.it.md`, `.es`, `.fr`, `.de`, `.pt`, `.nl`, `.sv`, `.pl`, `.cs`,
  `.ru`, `.ja`, `.ko`, `.zh`): изменение вносится во все.

Помощь приветствуется: см. [CONTRIBUTING.md](.github/CONTRIBUTING.md).
