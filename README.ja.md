# DagaDyn

[English](README.md) · [Italiano](README.it.md) · [Español](README.es.md) · [Français](README.fr.md) · [Deutsch](README.de.md) · [Português](README.pt.md) · [Nederlands](README.nl.md) · [Svenska](README.sv.md) · [Polski](README.pl.md) · [Čeština](README.cs.md) · [Русский](README.ru.md) · **日本語** · [한국어](README.ko.md) · [中文](README.zh.md)

オブジェクトを動かす SketchUp 拡張機能です。グループ、コンポーネント、断面平面のあらゆるプロパティが、選んだ時間で、自分で描いたカーブに沿って、ある状態から別の状態へ移り、それがシーンの中で見えます。開くドア、上がるエレベーター、点くランプ、建物を横切る断面。

⬇ **ダウンロード**: [最新バージョン](https://github.com/Dagadam/dagadyn/releases/latest)（すべてのバージョン: [Releases](https://github.com/Dagadam/dagadyn/releases)）

🛏 **サンプル**: [すべてが動く寝室](examples/README.md)（`examples/bedroom.skp`）。DagaDyn のすべての機能を使っています。

## できること

- **プロパティ**: 移動（今の位置から）、位置、回転、寸法（幅・奥行き・高さ）、尺度、色、不透明度、表示、タグ。断面平面は移動し、オン・オフも切り替わります。
- **状態とカーブ**: 各プロパティに開始状態、終了状態、長さがあり、状態を足すと連続した動きになります。遷移はカーブに沿って進みます：直線、加速、減速、行き過ぎ、バウンド、弾性、階段、またはカーブエディターで点をドラッグして描く自分のカーブ。
- **タイムライン**: 再生、一時停止、停止と、任意の瞬間を見るバー。1 回、ループ、往復を好きな速度で。
- **時間の速さ**: タイムライン横の **⏱** ボタンで、遷移と同じようなカーブでモデル全体の時間の流れを決めます。急ならタイムラプス、緩やかならスローモーション。再生はタイムラインより短くも長くもできます。
- **数式とリンク**: 遷移はカーブの代わりに数式に従うことができ (例: `v0 + (2 - v0) * u`)、パラメーターで他のオブジェクトのものも含め他のトラックを読めます: その値や、その遷移の一つの進み具合。立方体が伸びると板が広がります。 → [`formulas.skp`](examples/README.md#formulas-objects-that-read-each-other)
- **開始**: タイムラインと同時、別のオブジェクトの終了後（さらに待機）、または**操作したとき**：*操作* ツールでクリック。毎回最初から、または進んで次回は戻る（ドア、引き出し）こともできます。
- **ついていくチェーン**: 進んで戻るオブジェクトの後ろにチェーンでつないだオブジェクトは、その向きに合わせて行きも帰りも動き、それぞれ前のものが終わってから始まります（レバー、続いて跳ね橋）。
- **プロジェクトは変わりません**: アニメーションはモデルに手を加えずにオブジェクトを動かします。*停止* ですべて元どおり、ファイルには常に静止状態が保存されます。*保持* はオブジェクトを今の状態のまま残します（Ctrl+Z で元に戻せます）。
- **オブジェクトの中に**: アニメーションは `.skp` ファイルに保存され、オブジェクトと一緒にコピーされます。複数を選択すると変更はすべてに適用され、位置と寸法はそれぞれに合わせられます。
- **ビューに軌跡**: 動くオブジェクトの道筋と、状態ごとの点（SketchUp 2023 以降）。
- **編集中のプレビュー**: 状態の値を変えると、オブジェクトがその状態で表示されます。
- **単体でも [DagaWASD](https://github.com/Dagadam/dagawasd) と一緒でも**: DagaDyn はほかに何も必要としません。DagaWASD 1.3.0 以降も入っていれば、歩行・探索・ルート再生・ビデオ書き出しの間もオブジェクトが動きます（ビデオの時間に合わせて 1 フレームずつ）。動く床があなたを運び、操作キーで「操作したとき」に始まるオブジェクトが動き出します。
- 36 言語のパネル。DagaWASD が入っていれば、その言語と外観に合わせます。
- **アクセシビリティ**: [ACCESSIBILITY.md](.github/ACCESSIBILITY.md) を参照。

動作環境: SketchUp 2023 以降。Windows で開発・テストしています。Mac ではまだテストしていません。

## 使い方

1. *拡張機能 › DagaDyn › アニメーションパネル…*（またはツールバー）。
2. グループ、コンポーネント、または断面平面を選択します。*アニメーション › オブジェクト* でアニメーションするプロパティを選び、*追加* を押します。
3. 開始状態と終了状態（*⌖ 現在* はオブジェクトの今の値を使います）、長さを入力し、カーブを選びます。小さなカーブをクリックすると自分で描けます。
4. **▶**（またはパネルで Space）を押します。**⏹** ですべて元どおりです。

「操作したとき」に始まるオブジェクトには、*操作* ツール（ツールバーまたはメニュー）を選び、モデル内のオブジェクトをクリックします。Esc でツールを終了します。マウスの下で、動き出すオブジェクトが枠と名前で示されます。タイムラインで始まるオブジェクトがないときは、**▶** ボタンが **☝**（*操作* ツール）になります。

## インストール

[最新バージョン](https://github.com/Dagadam/dagadyn/releases/latest)（*Assets* の中）から **`dagadyn-<バージョン>.rbz`** をダウンロードし、*拡張機能 › Extension Manager › 拡張機能をインストール* からインストールします。

設定は `%APPDATA%\DagaDyn\settings.json` に保存され、更新しても消えません。アニメーションは拡張機能ではなくモデルの中にあります。

## 開発

コード、コメント、変更履歴はイタリア語です。拡張機能の内部構造は [SVILUPPO.md](SVILUPPO.md) にあります。

- `installa.bat` は見つかったすべての SketchUp の Plugins フォルダーにソースをコピーします。
- `tools\run_tests.bat` でテストを実行します（SketchUp を模した Ruby。カーブのテストには Node.js も必要）。
- `ruby tools\test_live.rb` は DagaWASD のブリッジを通して実際の SketchUp でテストします（新しいモデル（*ファイル › 新規*）を開いておく必要があり、最後は新しいモデルに戻します）。
- `ruby tools\crea_rbz.rb` で `dist\` にパッケージを作ります。
- バージョン番号は `dagadyn.rb`（`VERSION`）にだけあり、各バージョンは `CHANGELOG.md` に節があります。
- この README は複数の言語にあります（`README.md` は英語、`README.it.md`、`.es`、`.fr`、`.de`、`.pt`、`.nl`、`.sv`、`.pl`、`.cs`、`.ru`、`.ja`、`.ko`、`.zh`）。変更はすべてに反映してください。
